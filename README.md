## 🚀 How to Enable GitHub Pages
1. Go to repository **Settings** on GitHub (`https://github.com/AkramAli945/portfolio/settings/pages`).
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. In ~1-2 minutes, GitHub will publish the site live at `https://akramali945.github.io/portfolio/`.
